# Gangar-solder-pcb

An Pokemon theme  PCB designed by **Hemanta Sapkota**, made with KiCad.

The front has 6 LEDs paired with resistors including a switch, which are powered by battery cells. And there is a Spider on the front as my love for superheroes. Talking about the back, there is a cool-looking skeleton showcasing my interest towards anime .
